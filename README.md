## Programming

- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com) - Beginner-friendly book on using Python for everyday tasks.
- [Eloquent JavaScript](https://eloquentjavascript.net) - A modern introduction to JavaScript, programming and the web.
- [Exercism](https://exercism.org) - Coding practice in 70+ languages with free mentoring.
- [freeCodeCamp](https://www.freecodecamp.org) - Interactive lessons and projects covering web development, Python and more.
- [Learn Git Branching](https://learngitbranching.js.org) - Visual, interactive way to learn Git.
- [MDN Web Docs](https://developer.mozilla.org) - The reference and tutorials for HTML, CSS and JavaScript.
- [roadmap.sh](https://roadmap.sh) - Visual step-by-step learning paths for developer roles.
- [The Missing Semester of Your CS Education](https://missing.csail.mit.edu) - MIT course on the tools every developer should know: shell, Git, debugging and more.
- [The Odin Project](https://www.theodinproject.com) - Open-source full-stack web development curriculum.

## Computer Science

- [Crafting Interpreters](https://craftinginterpreters.com) - Free book on building programming language interpreters from scratch.
- [CS50](https://cs50.harvard.edu/x/) - Harvard's introduction to computer science, free online.
- [MIT OpenCourseWare](https://ocw.mit.edu) - Lecture notes, assignments and videos from real MIT courses.
- [Nand2Tetris](https://www.nand2tetris.org) - Build a complete computer from logic gates up to a working game.
- [Teach Yourself Computer Science](https://teachyourselfcs.com) - Curated study plan with the best free books and courses per CS topic.

## Data Science and AI

- [fast.ai](https://course.fast.ai) - Practical deep learning course for coders.
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) - Fast-paced introduction to machine learning with exercises.
- [Hugging Face Learn](https://huggingface.co/learn) - Free courses on LLMs, NLP, agents and more.
- [Kaggle Learn](https://www.kaggle.com/learn) - Short, hands-on micro-courses on Python, pandas, ML and more.

## Math and Science

- [3Blue1Brown](https://www.3blue1brown.com) - Visual explanations of math concepts.
- [Desmos](https://www.desmos.com) - Free online graphing calculator and interactive math activities.
- [Khan Academy](https://www.khanacademy.org) - Lessons and exercises from basic math to college-level science.
- [OpenStax](https://openstax.org) - Free peer-reviewed college textbooks.
- [Paul's Online Math Notes](https://tutorial.math.lamar.edu) - Clear notes on algebra, calculus and differential equations.
- [PhET Interactive Simulations](https://phet.colorado.edu) - Interactive science and math simulations.
- [Project Euler](https://projecteuler.net) - Math and programming challenges that grow in difficulty.

## Languages and Writing

- [Duolingo](https://www.duolingo.com) - Gamified language lessons with a free tier.
- [Forvo](https://forvo.com) - Pronunciation dictionary recorded by native speakers.
- [Purdue OWL](https://owl.purdue.edu) - Writing and grammar guides.
- [Tatoeba](https://tatoeba.org) - Huge collection of example sentences with translations.

## Contributing

Contributions are welcome! Please read the [contribution guidelines](CONTRIBUTING.md) first.

Quick rules:

- The resource must be completely free (a free tier alone does not count unless the useful content is fully accessible).
- Add one resource per pull request, in alphabetical order within its section.
- Use the format: `- [Name](url) - Short description starting with a capital letter and ending with a period.`
