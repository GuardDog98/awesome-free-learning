# Contribution Guidelines

Thanks for helping make this list better! Please read these guidelines before opening a pull request.

## What belongs in this list

A resource must be:

- **Completely free.** The useful content must be accessible without paying. "Free trial" or "free tier with the good parts locked" does not count.
- **High quality.** Well-made, accurate and useful for learners.
- **Maintained.** The link works and the content is not badly outdated.
- **Educational.** Courses, books, tutorials, tools or references that teach something.

## What does not belong

- Resources that require payment to access the main content
- Affiliate or referral links
- Your own course or blog post that is mostly a sales funnel
- Duplicates of resources already in the list
- Content that infringes copyright (pirated books, leaked courses)

## Format

Every entry follows this format:

```
- [Name](https://example.com) - Short description starting with a capital letter and ending with a period.
```

- Keep the description to one sentence and neutral (no "best", "amazing", "ultimate").
- Use the official name of the resource.
- Keep entries in **alphabetical order** within their section.
- Do not add trailing spaces or extra blank lines.

## How to add a resource

1. Fork the repository.
2. Add your entry to the most fitting section in `README.md`.
3. Open a pull request with **one resource per PR** and a short title, for example: `Add Exercism`.

## Pull request checklist

Before submitting, make sure that:

- [ ] The resource is completely free
- [ ] The link works
- [ ] It is not already in the list
- [ ] It follows the format above and is in alphabetical order
- [ ] The PR adds only one resource

## Suggesting a new section

If nothing fits, open an issue first and explain why a new section is needed. A section needs at least 3 good resources.

## Fixing and removing

- Found a broken or outdated link? Open a PR with the fix, or an issue.
- A resource became paid? Open an issue or PR to remove it.

## Review process

Maintainers check that the resource is free, relevant and correctly formatted. We may ask for changes. PRs that do not follow these guidelines may be closed.

## Code of conduct

Be kind and respectful. Disagreements are fine, personal attacks are not.
